## 📋 Overview

**DevSecure AI** is an enterprise-grade security platform that helps organizations securely manage secrets, detect security vulnerabilities, and automate security operations using AI-powered scanning.

### ✨ Key Features

| Category | Features |
|----------|----------|
| 🔐 **Authentication** | JWT-based auth, bcrypt password hashing, Session management |
| 🏢 **Organizations** | Multi-tenant workspaces, Team invitations, Role-based access |
| 🔒 **Secrets Vault** | AES-256 encryption, Secure API key storage, Audit logging |
| 🔍 **Security Scanner** | GitHub repository scanning, Secret pattern detection, Real-time alerts |
| 👥 **Access Control** | Admin, Developer, Viewer roles, Permission-based routing |

## 🛠️ Tech Stack

### Frontend
- **React 18** - UI Framework
- **Tailwind CSS** - Styling
- **Axios** - API calls
- **React Router** - Navigation
- **React Hot Toast** - Notifications

### Backend
- **Node.js** - Runtime
- **Express.js** - Web framework
- **PostgreSQL** - Database
- **JWT** - Authentication
- **bcrypt** - Password hashing
- **AES-256** - Encryption

### APIs & Integrations
- **GitHub API** - Repository scanning
- **Supabase** - Database hosting
