
# 🔒 DevSecure AI - Enterprise Security Platform

[Live Demo Link] | [Documentation]

## Features
- 🔐 **Secure Authentication** - JWT-based auth with bcrypt
- 🏢 **Multi-Tenant Organizations** - Isolated workspaces for companies
- 🔒 **AES-256 Secrets Vault** - End-to-end encrypted API key storage
- 🔍 **GitHub Security Scanner** - Detects leaked secrets in repositories
- ⚡ **Real-time Security Alerts** - Instant notifications for breaches
- 👥 **Role-Based Access Control** - Admin/Developer/Viewer permissions

## Tech Stack
- **Frontend**: React, Tailwind CSS, Axios
- **Backend**: Node.js, Express, PostgreSQL
- **Security**: AES-256, JWT, bcrypt
- **Deployment**: Docker, Render.com
